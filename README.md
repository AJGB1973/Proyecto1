# Actividad: GitHub Copilot y sistema de recomendacion

## Proceso realizado

1. [ ] Ingrese a GitHub y solicite/active la cuenta de estudiante de GitHub Copilot.
2. [ ] Cree el repositorio en GitHub: [Proyecto1](https://github.com/AJGB1973/Proyecto1).
3. [ ] Clone el repositorio en Visual Studio Code usando su URL HTTPS:

   ```bash
   git clone https://github.com/AJGB1973/Proyecto1.git
   ```

4. [x] Cree `recommendation_system.py` con un ejemplo de sistema de recomendacion usando GitHub Copilot.

5. [ ] Agregue los archivos, haga commit y suba los cambios al repositorio:

   ```bash
   git add .
   git commit -m "Agregar sistema de recomendacion"
   git push
   ```

6. [ ] Cree un archivo `.txt` o Word con el enlace del repositorio y entreguelo en el espacio habilitado por el docente en el AAI.
